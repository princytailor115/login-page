# 🔐 Login Page

A simple, clean, and fully responsive login page built using **HTML** and **CSS**.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

## ✨ Features
- 🎨 Clean and modern UI design
- 📱 Fully responsive — works on mobile, tablet & desktop
- 📧 Email and password input fields with validation styling
- 🖱️ Smooth hover and focus effects on button and inputs
- ⚡ Lightweight — no frameworks, pure HTML/CSS

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🚀 How to Use
1. Clone this repository
```bash
   git clone https://github.com/princytailor115/login-page.git
```
2. Open `index.html` in your browser
3. Enter credentials to see the login form in action
